
# Interview Tracker

Interview Tracker is a React-based application that helps manage interview preparation questions and track progress.

## Features

- Search interview questions
- Filter questions by category, difficulty, and status
- Track completed and pending questions
- View preparation progress through charts
- Responsive dashboard UI

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Context API
- Recharts
- Lucide React

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd Interview-Tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

## Purpose

The goal of this project is to organize interview preparation questions and make progress tracking easier.
