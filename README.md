# Interview-Tracker
Interview Tracker

Interview Tracker is a React-based application that helps users manage interview preparation questions in one place. 
It provides options to search questions, filter them by category, difficulty, and status, and track preparation progress through a dashboard.

Features
Dashboard to track preparation progress
Search questions by keyword
Filter questions by category, difficulty, and status
View completed and pending questions
Visualize question categories with charts
Clean and responsive user interface

Tech Stack
React
JavaScript
Tailwind CSS
Context API
Recharts
Lucide React
